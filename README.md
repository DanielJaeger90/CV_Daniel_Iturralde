# Daniel Iturralde — CV

Currículum interactivo en formato web, con estética de terminal / sistema operativo. Un solo archivo HTML, sin dependencias ni frameworks.

**Demo en vivo:** `https://danieljaeger90.github.io/CV_Daniel_Iturralde/`

## 📸 Vista previa

> Terminal con secuencia de arranque, bloque de identidad estilo `neofetch`, y secciones organizadas como comandos (`cat perfil.txt`, `ls -la experiencia/`, `./skills.sh --list`...).

## 🧩 Contenido

- Perfil profesional
- Experiencia laboral (técnica y complementaria)
- Educación y certificaciones
- Lenguajes de programación y sistemas
- Formación continua
- Proyectos personales
- Datos de contacto

## 🛠️ Tecnología

- HTML5 + CSS3 (sin frameworks)
- JavaScript vanilla para la animación de arranque
- Responsive (móvil / escritorio)
- Respeta `prefers-reduced-motion`
- Hoja de estilos de impresión incluida

Un único archivo (`index.html`), sin build ni dependencias que instalar.

## ▶️ Ver en local

Clona el repositorio y abre `index.html` directamente en el navegador:

```bash
git clone https://github.com/DanielJaeger90/NOMBRE-DEL-REPO.git
cd NOMBRE-DEL-REPO
```

Después haz doble clic en `index.html`, o ábrelo con "Live Server" desde tu editor.
